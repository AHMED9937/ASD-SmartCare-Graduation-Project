# Features & Functionality

ASD SmartCare provides a rich set of features tailored for both parents/caregivers and healthcare professionals. This document describes the user-facing capabilities of the app.

---

## 👨‍👩‍👧 Parent Module

The parent module focuses on early detection, development tracking, and educational support.

### 🧩 1. AI-Powered Autism Screening
- **Multi-tier Assessment**: 
    - **Tier 1 (Autism Test)**: Comprehensive questionnaire for initial symptom detection.
    - **Tier 2 (Autism Level Checker)**: AI analysis of behavioral patterns to predict severity (Mild, Moderate, Severe).
- **Interactive UI**: Step-by-step wizard with age-appropriate inputs and visual feedback.

### 📊 2. Developmental progress Tracking
- **Skill Mapping**: Track progress across Cognitive, Social, Communication, and Daily Living skills.
- **Visual Analytics**: Interactive charts showing improvement over time.
- **History**: View past screening results to monitor longitudinal changes.

### 🤖 3. Intelligent Chatbot
- **Context-Aware Support**: Powered by AI to answer questions about ASD symptoms, coping strategies, and local resources.
- **Immediate Response**: 24/7 availability for parent concerns.

### 👨‍⚕️ 4. Doctor Discovery & Booking
- **Smart Filters**: Search for specialists by location, specialty, or rating.
- **Booking Engine**: View real-time availability and schedule appointments.
- **Payment Integration**: Secure, in-app payments via Stripe.

### 📚 5. Educational Resources
- **Curated Articles**: Access a library of articles vetted by clinicians.
- **Media Support**: Support for images and PDFs within educational materials.

---

## 👨‍⚕️ Doctor Module

The doctor module provides tools for managing appointments and patient care.

### 📅 1. Appointment Management
- **Availability Calendar**: Doctors can set their working hours and session availability.
- **Booking Management**: Accept, reschedule, or cancel patient appointments.

### 👥 2. My Patients (Caseload)
- **Patient Profiles**: Access registered children profiles and their previous screening history.
- **Longitudinal Tracking**: View the progress data shared by parents.

### 📝 3. Therapy Sessions
- **Session Notes**: Record clinical observations during or after sessions.
- **Reviews**: View feedback from parents to improve service delivery.

---

## 🤝 Shared Features

### 🔐 Authentication & Onboarding
- **Dual-role Signup**: Specialized journeys for parents and doctors.
- **Profile Management**: Update professional credentials (doctors) or family info (parents).

### 💳 Payments & Donations
- **Secure Transactions**: Fully integrated Stripe checkout for session bookings.
- **Charity Support**: Browse and donate to verified autism-related charities.

### 💊 Medicine Guide
- **Searchable Database**: Look up common medications and their intended uses within the ASD context.
