# Screenshots

This directory is reserved for app screenshots and visual assets for documentation.

## Recommended Screenshots

When capturing screenshots for documentation, include:

1. **Onboarding Flow**
   - `onboarding_welcome.png` - Initial welcome screen
   - `onboarding_role_selection.png` - Parent/Doctor role selection

2. **Parent Module**
   - `parent_home.png` - Parent dashboard
   - `screening_start.png` - ASD screening test start
   - `screening_result.png` - Screening results display
   - `progress_tracking.png` - Child progress charts
   - `doctor_search.png` - Doctor discovery screen
   - `appointment_booking.png` - Booking flow

3. **Doctor Module**
   - `doctor_home.png` - Doctor dashboard
   - `appointments_list.png` - Appointment management
   - `patient_details.png` - Patient information view

4. **Shared Features**
   - `login.png` - Login screen
   - `chatbot.png` - AI chatbot interface

## Screenshot Guidelines

- **Resolution**: Capture at 1080x1920 (mobile portrait)
- **Format**: PNG for quality, WebP for optimization
- **Naming**: Use `snake_case.png` format
- **Content**: Remove any personal test data before capturing

## Usage in Documentation

Reference screenshots from README or docs like:

```markdown
![Parent Dashboard](docs/screenshots/parent_home.png)
```
